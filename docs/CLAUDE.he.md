# Claude לצד Codex

[English](CLAUDE.md)

**לפני חיבור ספק:** בדקו בעצמכם את תנאי השימוש העדכניים של הספק. האחריות לעמוד בהם היא שלכם. תנאים יכולים להשתנות, וחיבור שעובד היום עלול להפסיק לעבוד. StellarCortex אינו אומר ששימוש בחשבון או במנוי של ספק כלשהו מותר, ואינו קשור לאף ספק. פרטים ב[תנאי הספקים](../README.he.md#provider-terms).

StellarCortex מאפשר לבחור ספק לכל בוט: Codex או Claude. בוטים משני הספקים משתמשים באותן שיחות, קבוצות, מסירת משימות, זיכרון, שגרות, ספרייה ומחשב בוט. כל בוט משתמש במכסת המנוי שלו. שינוי ספק חל על המשימה הבאה; משימה שכבר התחילה נשארת בספק המקורי שלה.

## התחברות

המתקין מוריד את חבילת Claude Code הרשמית והמקורית כתלות אופציונלית. אם התקנתה נכשלת, Codex נשאר זמין והגדרות Claude מציגות את התקלה. נדרשים מערכת שנתמכת ב־Claude Code וחשבון עם גישה אליו.

1. לחץ על **חיבור Claude** בהגדרות: השרת מריץ את הכניסה הרשמית, האפליקציה מציגה את קישור הכניסה, ואם מוצג קוד מדביקים אותו שם. אפשר גם להריץ `bash claude-login.sh`, או להעתיק את פקודת הכניסה מההגדרות של Claude: היא כוללת נתיב מלא ואת הסביבה של השירות, ועובדת מכל תיקייה.
2. השלם את ההתחברות בחלון הרשמי של Claude Code ובדפדפן שנפתח. StellarCortex אינו מקבל סיסמה או אסימון OAuth. קוד כניסה שמדביקים בהגדרות עובר דרך האפליקציה אל Claude Code ואינו נשמר.
3. חזור להגדרות StellarCortex ובדוק מחדש את חיבור Claude.
4. צור בוט או ערוך בוט קיים ובחר Claude. גם הבורר ליד כתיבת ההודעה מאפשר לשנות ספק ומודל.

בשרת מרוחק יש להריץ את ההתחברות **בשרת, כמשתמש שמריץ את StellarCortex**. חשבון שמחובר במחשב אחר אינו מחובר בשרת או בתוך container. פרטים ב־[DEPLOYMENT.md](DEPLOYMENT.md).

ב־Docker:

```bash
docker compose exec stellarcortex node scripts/claude-auth.mjs
```

Compose שומר את תיקיית התצורה הרשמית של Claude ב־volume נפרד. אין להעביר אישורי כניסה דרך ייצוא בוט או חבילת התקנה. הפעלה חדשה דורשת התחברות אישית של הבעלים.

## מודלים, מאמץ ומהירות

הבורר מציג **גרסאות מדויקות**, למשל `claude-sonnet-5-5`, בנפרד מכינויים מתעדכנים כמו `sonnet`. אפשר לקבע גרסה או לבחור כינוי שמאפשר ל־Claude Code לעדכן את הדגם בעתיד. הרשימה נקראת מפרוטוקול האתחול של Claude Code המקורי בלי לשלוח הודעת משתמש ובלי בקשת מודל. התשובה כוללת את מזהה הגרסה ואת רמות המאמץ שה־CLI מפרסם. אם גילוי הרשימה נכשל, מוצגת רשימת גרסאות מהתיעוד הרשמי עם סימון שהזמינות לא אומתה; הזכאות הסופית עדיין נבדקת על ידי Claude Code בתחילת המשימה.

ברירת המחדל היא ברירת המחדל של חשבון Claude. מודל Codex הכללי לא משפיע על בוטי Claude. שגיאת זכאות מוצגת למשתמש ואין מעבר אוטומטי למודל או לחשבון אחר.

אפשרויות המאמץ תלויות בדגם ובגרסת Claude Code. מצב המהירות הנתמך בשילוב זה הוא Standard. לא מוצע כאן Fast של Claude, מפני שהתיעוד שלו קושר אותו לחיוב שימוש נוסף מעבר למכסת המנוי. אין מעבר אוטומטי לחיוב API.

מעבר ספק מאפס בחירות מודל, מאמץ ומהירות שאינן שייכות לספק החדש. היסטוריית השיחה בממשק נשמרת, והספק החדש מקבל הקשר מההודעות האחרונות. סשנים של שני הספקים נשמרים בנפרד; היסטוריה פנימית מלאה של מודל אחד אינה מועתקת למודל האחר.

## הפעלה והרשאות

השילוב מפעיל את Claude Code המקורי במצב מתוכנת עם פלט זורם. כלי StellarCortex מועברים אליו דרך שרת MCP מקומי לכל משימה. קריאות כלי ושיחות בין בוטים עוברות במנוע המשותף ונראות בממשק. אישורים לפעולות Claude Code מועברים לתיבת האישורים של StellarCortex. עצירת משימה סוגרת גם את תהליך Claude Code ואת חיבור הכלים שלה.

כלי הקבצים פועלים במצב `--restricted` וסביבת העבודה היא תיקיית `workspace` של ההתקנה. פקודות מערכת וכתיבות דורשות אישור. זה אינו VM או הפרדת משתמשי מערכת: לפקודת מערכת שאושרה יש הרשאות משתמש השרת. לצורך הפרדה מהמחשב האישי יש להשתמש בסביבת Linux/container/VM ייעודית כפי שמפורט במדריך הפריסה. חיבורי MCP אישיים, plugins והגדרות משתמש של Claude אינם נטענים אוטומטית בשילוב המוגבל הזה.

## אבחון

בתפריט החשבון ובהגדרות השימוש יש מדים נפרדים ל־Codex ול־Claude. מד Claude נקרא מהפקודה הרשמית `claude -p "/usage" --output-format json`. זו פקודה מקומית של Claude Code, שאינה מפעילה מודל. מוצגים אחוזי ניצול החלון הנוכחי והמכסה השבועית, זמני איפוס ומועד העדכון האחרון. אחוזים אינם מחושבים מספירת tokens. רענון ידני מבקש דוח חדש; קריאות רגילות יכולות להשתמש במטמון קצר. כאשר הקריאה נכשלת, מידע שמור מסומן כישן, ונתון חסר אינו מוצג כאפס.

האפליקציה שומרת רק את נתוני המכסות הדרושים למדים. היא אינה שומרת את הדוח הגולמי, אסימוני חשבון או את פירוט תרומת השיחות המקומיות לשימוש.

```bash
node scripts/claude-auth.mjs --status
npm run doctor
```

בדיקת התחברות אינה מבצעת בקשת מודל ואינה מוכיחה זכאות לכל דגם. כדי לאמת חשבון בפועל, שלח הודעה קצרה לבוט Claude לאחר ההתחברות.

מקורות: [התחברות רשמית](https://code.claude.com/docs/en/authentication), [הפעלה מתוכנתת](https://code.claude.com/docs/en/headless), [דגלי CLI](https://code.claude.com/docs/en/cli-reference), [עמוד המשפטי של Claude Code](https://code.claude.com/docs/en/legal-and-compliance). תוצאות הבדיקה של גרסה זו מפורטות ב־[VALIDATION.md](VALIDATION.md).

## מצבי הרשאות

בהגדרות ניתן לבחור מצב ידני, אוטומטי או חופשי (מסוכן), עם הגדרה נפרדת לכל בוט. מצב אוטומטי משתמש בבדיקת Claude ואינו עוקף הרשאות. מצב חופשי דורש אישור לשמירה אך חסום בפועל תחת --restricted; אין הסרה של גבולות סביבת העבודה. [פרטים ומגבלות](UPDATES.md).
