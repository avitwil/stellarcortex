# מודל, מהירות ומאמץ לכל בוט

[English](MODELS.md)

בורר **הספק** כולל Codex ו־Claude דרך מנוי, OpenAI API, Claude API, מודל מקומי וכל חיבור API אישי שהוספת בהגדרות. לכל ספק אישי שם משלו ורשימת מודלים מהשרת שלו; הוספת ספק אינה דורשת שם מודל. Claude Code מציג גרסאות מדויקות בנפרד מכינויים מתעדכנים; רשימת הדגמים ורמות המאמץ נקראת מה־CLI הרשמי. שינוי ספק מאפס את בחירות המודל, המאמץ והמהירות, ושומר את השיחה הגלויה. [פרטי Claude ומדי השימוש](CLAUDE.he.md) · [חיבורי API ומנועים מקומיים](API-LOCAL.he.md).

ליד אזור כתיבת ההודעה יש בורר לכל בוט: רמת המאמץ מעל המחוון, שם מודל שניתן לבחור, כפתור ברק למהירות וכפתור איפוס לברירות המחדל. אותן אפשרויות נמצאות גם ביצירה ובעריכה של בוט:

- **מודל:** בחירה מתוך הרשימה שמחזיר חשבון Codex המחובר. ברירת המחדל משתמשת במודל הכללי של StellarCortex; אם הוא לא הוגדר, במודל ברירת המחדל של Codex.
- **מאמץ חשיבה:** הרשימה מתעדכנת לפי המודל שנבחר, ובסדר שמפרסם Codex. ברירת המחדל היא רמת המאמץ של אותו מודל.
- **מהירות:** רגילה, או דרגות נוספות שהמודל מפרסם לחשבון, כגון Fast. ברירת המחדל היא המהירות של המודל. מצב מהיר ומאמץ גבוה עשויים לצרוך יותר ממכסת המנוי; מהירות בפועל תלויה גם במשימה ובשירות.

ההגדרות נשמרות בנפרד לכל בוט וחלות על המשימה הבאה שמתחילה. משימה פעילה ממשיכה בהגדרות שבהן התחילה. אותה בחירה משמשת גם בשיחה קבוצתית, בשגרה, בהעברת משימה לבוט ובאיסוף התוצאה על ידי הבוט המתאם. בוט שמקבל עבודה משתמש בהגדרות שלו.

אפשר להחזיר כל שדה לברירת המחדל. שינוי מודל או איפוס ההגדרות לא מוחק את השיחה. ההרצה שולחת בחירות מפורשות גם בהמשך של שיחה קיימת, כדי שלא תישאר בטעות מהירות או רמת מאמץ שנבחרה בעבר.

הזמינות נקבעת לפי החשבון, המודל וגרסת Codex; אין רשימת מודלים קבועה בקוד. בחירה שמורה שכבר אינה זמינה מוצגת ככזאת, ולא מוחלפת בשקט במודל אחר. ייצוא תבנית כולל את בחירות המודל, ובייבוא הן נבדקות מול החשבון המקבל.

המימוש ממשיך להשתמש במנוי ChatGPT/Codex המחובר; אין מעבר אוטומטי לחיוב API.

מקורות: [גילוי מודלים והגדרות לכל הרצה](https://learn.chatgpt.com/docs/app-server), [מהירות ב־Codex](https://learn.chatgpt.com/docs/agent-configuration/speed). המימוש נבדק גם מול סכמת הפרוטוקול של חבילת Codex המותקנת. תוצאות הבדיקות מופיעות ב־[VALIDATION.md](VALIDATION.md).
